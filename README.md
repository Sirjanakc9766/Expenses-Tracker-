# Expenses Tracker Management System

## Description
A console-based Java application for managing personal expenses.

## Features
- Add expenses
- View expenses
- Edit expenses
- Calculate total expenses
- Automatic expense ID
- Automatic date and time

## Technologies Used
- Java
- ArrayList
- LocalDateTime
- Scanner

## Project Structure
Main.java
Expenses.java
ExpensesTracker.java

## How to Run
1. Clone the repository
2. Open the project in a Java IDE
3. Run Main.java
